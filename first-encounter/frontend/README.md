# 前端

Vue 3 + TypeScript + Vite。当前 src/App.vue 只提供空白页面，src/style.css 设置白色背景和系统字体。

在此目录执行：

- `npm ci`：按锁文件安装依赖。
- `npm run dev`：启动浏览器开发服务。
- `npm run build`：检查 TypeScript 并构建。
- `npm run preview`：预览构建产物。

桌面开发在上一级目录执行 `wails dev`。wailsjs/ 由 Wails 生成，不手动修改。
